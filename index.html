01 Product

Stampwise, a quotation agent
for pressure vessel fabricators.

Our first product, Stampwise, is a Claude powered quotation and engineering agent for ASME pressure vessel fabricators. It reads an RFQ package, extracts every requirement line by line, flags gaps and drafts a reviewable quotation workbook. In daily use on live bids at a U stamp fabricator in Korea since early 2026.

01 / INTAKE

RFQ package reading

Specifications, data sheets, drawings and vendor forms go in. Claude extracts the requirements line by line and keeps a source reference for each one.

Useful for Turning a long RFQ package into a requirement list a reviewer can check in an hour.

Claude API · Long context · Document extraction

02 / GAPS

Gap and clarification lists

Missing data, conflicting revisions and unusual conditions are flagged before pricing starts, with a draft clarification list for the customer.

Useful for Catching a missing design pressure or an impact test requirement before it costs money.

Claude Code agents · Validation rules

03 / WORKBOOK

Reviewable quotation workbook

The agent drafts the quotation workbook: materials, fabrication, NDE, testing and quantities, each line traceable. The estimator reviews and signs off.

Useful for A consistent first draft on every bid instead of a blank spreadsheet.

Python · Excel · Deterministic pricing gates

04 / ONTOLOGY

Every number traced to its source

A Neo4j ontology links requirements, components, calculations and prices, so any figure in the quotation can be traced back to the clause or drawing it came from.

Useful for Answering where a number came from during customer review.

Neo4j · Ontology · Knowledge graph

05 / ENGINEERING

Deterministic ASME checks

Thickness and allowable stress checks run in deterministic code with source approved tables, never inside the language model. Claude prepares the inputs and explains the result.

Useful for Keeping ASME VIII Division 1 and 2 checks repeatable and inspectable.

Python · MCP tools · Source approved tables

06 / HUMAN SIGN OFF

Built for high stakes outputs

Pricing and engineering decisions stay with people. The agent proposes, flags and documents; a named reviewer approves every quotation before it leaves.

Useful for Using AI on bids without giving up control of the final number.

Review gates · Audit trail · Claude Agent SDK

02 How it works

Three steps from
RFQ to sign off.

The agent does the reading and the first draft. Your estimator keeps the judgement and the final number.

  1. 01↗

    Drop in the RFQ package.

    Specifications, data sheets, drawings and vendor forms, in English, Korean or both. Claude reads the whole package and indexes every clause.

  2. 02↗

    Review requirements and gaps.

    Every requirement comes with the clause it came from. Missing data and conflicts are flagged, with a draft clarification list for the customer.

  3. 03↗

    Approve the quotation draft.

    The workbook arrives with traceable lines and deterministic ASME checks. The estimator reviews, adjusts and signs off before anything is sent.

06 FAQ

Questions estimators ask.

More detail in the docs.

Who is it for?

Pressure vessel and heat exchanger fabricators, and other plant suppliers who quote against engineering RFQ packages.

What documents can it read?

PDF, Word and Excel files: specifications, data sheets, material requisitions, vendor forms and drawings in PDF. English, Korean and mixed packages.

Does the AI calculate ASME values?

No. Claude prepares inputs and explains results. Thickness and allowable stress checks run in deterministic code with source approved tables.

Where does our data go?

Documents are processed through the Claude API under Anthropic's commercial terms. SPS does not use them to train models. See the Privacy Policy.

How does a pilot work?

Six weeks on one product family and up to 20 of your real RFQ packages, with a weekly review and an evaluation report at the end. The fee is credited to year one if you subscribe within 30 days.

Can it handle workflows other than quotations?

Yes, as a custom deployment of the same agent stack, for example RFQ intake or engineering knowledge search. See Pricing.
